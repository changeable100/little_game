## 已确定的协作边界

A 持有游戏状态并负责输入/集成，B 持有 LVGL 对象及不可变正式关卡。所有 `maze_game_*` 操作在未来 UI 线程顺序调用；IMU 采样不访问 LVGL 和模型。UI 事件可在同一线程同步调用动作处理，返回值代表接受/拒绝；最终显示仍取模型快照，无需为本方案创建游戏任务或队列。UI 如果使用 `maze_action_sink_t` 回调，必须由 A 在 UI 线程提供，并立即返回。

首个增量仅启动自检，完成后继续 RGB 基线。没有生产中的假 IMU、假通关或界面。后续 B 用静态快照预览时依然要标模拟，不能记作实物通过。

## 数据契约 v1

- 地图：`maze_level_t`，0=路、1=墙，行优先 cells[row*cols+col]；尺寸最多 16×16，长度须完全匹配，起终点互异且为路。cells 静态只读、生命周期覆盖模型使用期间。B 验证可达性，A 检查安全边界；不复制另一份地图。
- 坐标：`float`，地图格为单位；起点是格中心 col+0.5/row+0.5，圆半径 0.20 格。B 按统一比例和偏移换算为像素，不能把格坐标当像素。
- 快照：run_id、revision、level_id、state、input_status、error_code、ball_x/y/radius、elapsed_ms。`maze_game_snapshot()` 复制快照；UI 不持有模型内部指针。
- 动作：START、PAUSE、RESUME、RESTART、BACK；携带 expected_run_id 与非零 request_id。request_id 在一个模型实例内严格递增，不随局号归零。旧局请求与重复请求拒绝；计数耗尽时返回明确错误并要求重建实例，禁止回绕接受旧请求。
- 新局：START 从 READY 或 RESTART 从任意状态建立新局号，清空位置/时间/速度并进入 CALIBRATING。`maze_game_calibrated(game, run_id)` 只接受当前局校准完成；随后 RUNNING。BACK 使局号更新并进入 READY，迟到校准不可生效。
- RUNNING → PAUSED 只接受 PAUSE，RESUME 只从 PAUSED 回 RUNNING。暂停时位置/时间冻结；通关后停止运动与计时。错误恢复通过 RESTART 后重新校准。
- 输入：step 接收有限 float [-1,1] 与有效标记，不接收 I2C 原始数据。NaN/Inf/范围外、无效标记或 dt 超过 100 ms 会进入 ERROR，速度归零，不产生位置或计时更新。READY/校准/暂停/通关/错误时 step 无动作；无效输入不会让暂停状态自动复活。
- 时间：调用者传入真实相邻步进毫秒差，正常设计周期 20 ms；最多 100 ms，分成最多 20 个 5 ms 子步。每子步积分、限速、碰撞，再检查终点。用时饱和到 UINT32_MAX，绝不回绕。模型无硬件 I/O、sleep、malloc 或无界循环。
- revision 在有状态变更或有效推进时递增，达到上限拒绝后续更新；UI 不使用会回绕的“更大就是更新”假设。

## 首轮验收：先有用例，再实现

| 用例 | 条件/操作 | 固定判据 |
|---|---|---|
| TC-301 | 合法地图启动，START、校准完成 | 局号增加，状态 READY→CALIBRATING→RUNNING；起点格心、时间清零；旧局校准拒绝 |
| TC-302 | 正负水平和垂直输入分别在独立模型推进 | 正x右移、负x左移、正y下移、负y上移，正交坐标不变；速度不超每轴3格/秒 |
| TC-303 | 连续向墙及地图外施加输入；用100 ms步长沿薄墙运动 | 圆不与墙体相交，不越出地图，不跨墙；允许沿自由轴滑动 |
| TC-304 | 运行后暂停，推进再继续、重开、返回 | 暂停位置/时间严格不变；继续可推进；重开归零进入校准；重复/旧局意图拒绝 |
| TC-305 | 沿无墙测试走廊到终点，再推进 | 进入终点格后 WON；继续 step 位置/时间不变，重开新局归零 |
| TC-306 | 错长地图/空指针/非法尺寸或格类型/起终点非法；NaN/Inf/失效输入/超时步长；计数临界值 | 错图拒绝，错误参数不越界；运行时输入/时序错误进入 ERROR，不移动或虚增时间；局号/request/revision/用时不回绕 |
