## 第一轮：先验证最小可玩流程

本轮游戏操作都点屏幕；串口只用于记录和查看。烧录重启后可发一次`maze_diag status`启用诊断，随后保留整段原文。不要用串口START/PAUSE代替触摸验证。等待时间是留给状态变化的建议，可以慢慢操作，不需卡秒。

| 操作 | 应看到什么 | 证据 |
|---|---|---|
| 点HOW TO PLAY再返回，点ENTER MAZE | 独立说明可返回；游戏为READY且用时0，进入本身不开始采样/新局 | 首页及游戏页照片、操作顺序 |
| 先把板放平，再点START | 屏幕CALIBRATING/保持平放提示，随后RUNNING；不是点击就假定成功 | 记录校准过程；日志cal32/state2/error0 |
| RUNNING后依次右沿/左沿/上沿/下沿压低并回平 | 屏幕小球对应向右/左/上/下，受墙挡住时可停在墙边；与日志tilt/pos一致 | 最好视频；或各段明确说明+照片/日志 |
| 用屏幕PAUSE | 变PAUSED，按钮改RESUME；等待数秒后时间和球位保持 | 暂停前后画面与日志 |
| 点RESUME | 回RUNNING，用时继续；若提示样本尚未就绪，保留日志后等待再点击，不认定按钮已经成功 | 恢复后的画面/日志 |
| 点RESTART，重新平放 | 新run、回起点、用时归零、重新校准后RUNNING；数秒后用时增长正常 | 从点击前起保留日志 |
| 点BACK回首页，再ENTER | 回独立首页并停采样；再进按实际模型状态显示，显式BACK后应READY新局 | 返回/重进画面、stopped/result0记录 |
