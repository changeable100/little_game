## 接口及阻塞点

`maze_ui_create(sink, context)` / `maze_ui_render(snapshot, level)` / `maze_ui_destroy()` 的语义见 `src/maze_ui.h`。UI 只在 LVGL 所在线程调用。create 返回独立的 UI 错误码，destroy 幂等。render 不持有调用者栈指针。

B2-1 只允许 NULL sink 的静态预览。START / PAUSE / RESTART 完整绘制但禁用；BACK 仅关闭模拟页，不发送模型意图。生产 sink 返回“尚未接入”，避免调用者误以为动作已可用。后续须先由 A 提供统一 request_id 生成/提交方式和新快照回送方式，再接按钮。B 不用 revision 猜 request_id、不伪造校准、不创建游戏 timer。

独立入口通过 Lab 首页的 `MAZE PREVIEW` 打开；不启动模型、IMU 或其他新服务。390×450 候选布局：顶栏 44px，游戏区 354px，底栏 52px；16×16 图每格 20px，地图左上 (35,61)，球圆心 (65,91)、半径 4px。页面显著显示 `PREVIEW / SIMULATED DATA`，状态 READY、时间 0s 均为固定模拟输入。A 核对后再推进 B2-2 动态六态。
