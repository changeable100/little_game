# ADR-0017 满屏构图与粉紫像素界面

2026-11-12，负责人提供两张真机照片，指出镜头过大、计时和菜单风格不协调，控件清晰度与游戏脱节。

备选A：场景投影缩小约25%，计时/菜单/校准准备/暂停结算整体改为粉紫像素风，块状字形、阶梯边框和硬边阴影。与原低分辨率场景一致，但需更新字库和所有浮层。

备选B：相同构图调整，保留柔和圆角，缩小控件并降低对比。改动较少，仍存在颗粒尺度差异。

负责人通过交互明确选择A。维持现有LVGL/物理/动作架构，200×232场景与2倍显示；统一调整投影焦距0.75倍，不修改物理或相机朝向。字体静态生成、矩形组合绘制，不新增动画定时器或大型离屏层。REQ-524/525的功能和触摸面积保留，实际风格及视野由真机新证据验收。
