# ADR-0002：连续滚动与单张固定迷宫的首版范围

- 状态：已采纳方案 A，2026-10-17
- 决策人：王若豪；协助：Codex / GPT-6
- 依据：学生审阅任务书后回复“选择方案 A，现在开始做”；沿用任务书各项 A（连续滚动、单线程步进、首版单图），已在开工说明。
- 关联需求：REQ-301、REQ-302、REQ-303、REQ-304、REQ-305、REQ-306

## 背景与备选

任务书给出 A 连续滚动、B 按格移动。连续滚动更直观，但必须处理碰撞和速度；格点移动实现较简单，需定义重复触发。首版范围 A 为固定单图，B 为多图/选关和可能的成绩记录。学生选择 A 后先完成可验证的小流程，再扩展。

## 决策

采用连续小球、单张固定地图、校准后开始、暂停/继续、到终点通关和重开。模型使用浮点地图格坐标（原点左上，x 右、y 下），半径初值 0.20 格，最大单轴速度 3 格/秒。输入为归一化倾斜 [-1,1]，运动用加速度、阻尼与限速；数值是初始实现参数，不是实测值，调参需保留前后手感记录。

计时只累计 RUNNING 的有效步进，暂停/校准/通关不累计。传感器无效时进入 ERROR，速度归零；恢复通过重新开始并校准，不能静默继续旧局。

## 后果

模型将每次最多 100 ms 的有效 dt 拆成最多 20 个 5 ms 步长防止跨墙，超出范围拒绝并进入错误，不追赶任意长卡顿。此策略保证计算量有上界；真实调度延迟超过 100 ms 为待解决异常，不通过缩短计时伪装正常。地图最多 16×16，B 负责通路验证及正式图；A 实施边界、长度、格类型、起终点等防御检查。

本增量的测试地图不是正式关卡。IMU 实物方向、噪声/校准阈值、显示/触摸及游戏完整手感在后续验证，当前不能声称完成可玩产品。
