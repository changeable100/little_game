# ADR-0016 结算锁定成绩并保留背景运动

2026-11-11，负责人纠正上一版停球和等满一秒后改文字的交互，要求0.8秒左右渐入结算面板、小球继续滚动、满屏HUD及暂停菜单。

备选A：首次接触绿色锁定成绩，物理继续按重力/接触自然滚动，面板渐入，滚出不撤销。优点是成绩稳定、结算过程连续，需把成绩计时与结算后运动推进区分。
备选B：要求一直留在绿色上，滚出取消结算。优点是停留挑战明确，但与自然滚动结合时可能出现结算反复收回。

负责人在交互中明确选择A；另明确本轮下一关置灰，后续设计正式新关卡，不用历史M1/M2冒充新路线。沿用独立物理所有者和页面刷新，M3可选WON后自然运动，旧回归世界保持停球。结算后停止IMU输入，成绩冻结，球的自然滚落不抹除结算；镜头保持在绿色区域。菜单手动暂停保存运动用于继续，迟帧恢复仍安全停止。完整头文件/实现需同步重编。
