# ADR-0019：先完成电脑端整关模型，再移植

2026-11-13，负责人指出金色存档台附近明显穿插，明确要求“现在电脑上建好模，知道地图长什么样之后再移植到板子上”。这取代此前一边修改固件一边依靠跟球截图确认布局的方式。

采用独立电脑模型：可旋转全貌、俯视、分层/拆层、隐藏柱体、选取部件和沿线示意，交付GLB/OBJ及自包含查看器。先修真实连接面和支承顶面，保留实体柱墙、紧凑路线、存档点、两段差异/正交陡降、冰蓝与绿色终点。确认完整模型后，另做碰撞网格/板端表示及真实可玩验收。

旧固件回放通过只能说明那条输入轨迹走通，不能证明几何不穿插。本阶段不构建/烧录新固件，也不把沿线示意称为物理仿真。板端32盒等约束留移植阶段评估，不为先通过预算而保留错误模型。


r2审阅修订：负责人明确两个紧弯、整体沿画面对角线推进、存档沿用第一关。这取代旧“金色SAVE台”和“折回起点下方”的具体外观/布局。采用两小内孔贴块曲面及实体尖脊、先前高台放后方、绿色终点放前方；第一关存档原面数据平移复用。固定方向视线验收与可旋转审阅继续先于移植。


2026-11-13后续：负责人明确“先移植第二关再验证，点play之后可以选关”。现授权将已完成电脑模型r4移植到生产两关选择固件，替代此前暂缓移植的阶段边界；真实硬件结果仍另验。
