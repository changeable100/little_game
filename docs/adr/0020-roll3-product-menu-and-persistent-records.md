# ADR-0020：3D专用菜单与断电保存排行榜

2026-11-13，负责人要求游戏风格启动菜单、排行榜并删除旧2D游戏；交互明确选择本机单次通关用时前10名、关机后保留。第二关仍遵循ADR-0019，仅电脑建模。

菜单沿用当前3D的短英文像素字与粉紫按钮、冰蓝棋盘元素，PLAY直达现有第一关，TOP 10显示真实完成记录，HOW TO说明操作。2D迷宫产品模型/控制器/运行时/UI/字库/菜单/自检与旧活动用例删除，原证据和Git历史保留；3D共享采样服务改名并保留原行为。校准常量转入3D头文件，数值32/5000/100不变。

持久化实现选择SDK已启用且带锁的同步NVDS/FlashDB键值接口，用R3_TOP10_A/B两个独立应用键，不创建/格式化新分区。替代方案为文件系统存储（当前仅devfs，需要配置与挂载工作）或新独立Flash分区（需要修改分区/固件配置）；本轮不采用。用户明确选择的是断电保存，已有SDK服务内的实现方式为授权功能范围内的常规实现。

纯C成绩核心记录每个run首次有效WON的冻结耗时/掉落，时间优先、同时间掉落少优先。带格式版本/CRC/代数的两个完整快照交替写入，读回确认成功再置已保存；后台保存线程低于物理线程与UI优先级，不让Flash操作进入物理/UI线程。多局在一次写入前合并时按实际有效槽选择另一槽，不能只按内存代数奇偶覆盖当前有效数据。异常状态分别显示保存中、未保存重试、不可用。逻辑与SDK编译通过不等于断电实测通过，真实Flash和重启持久化待负责人硬件证据。
