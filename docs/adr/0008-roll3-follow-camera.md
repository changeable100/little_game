# ADR-0008：近景跟随和宽平台赛道
- 日期：2026-11-09
- 状态：负责人明确回复“a”确认
- 关联：REQ-505 / TC-505；替代ADR-0007固定相机位置，保留固定朝向与轴映射。
A：相机拉近并平移跟球，宽平台/转弯/坡道与棋盘格，可辨球路，但不同时看全地图。
B：保持全景扩大区域、加宽道路；成本较低，长地图仍使球偏小。
负责人选择A，手感之后调整。接受局部视野，新增地图连续可通行回归；不改变IMU映射、摩擦、惯性、恢复系数。相机不旋转，避免改变操控轴。掉落时回看复活点，防止镜头追入虚空。

## 2026-11-09实现维护
用户随后报告运动地图抖动。按此缺陷反馈，在原固定朝向近景方案内加入视图拥有的焦点平滑/死区；不引入新线程、改操控轴或让渲染推进物理。首次/状态切换即时定位，正常帧按快照用时平滑。此前纯无状态焦点为初版历史实现，当前行为以REQ-506设计为准；效果待真机复测。
