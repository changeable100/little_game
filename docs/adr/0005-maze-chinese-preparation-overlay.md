# ADR-0005：中文游戏准备界面采用同页遮罩

- 日期：2026-11-08；状态：已采纳方案A
- 决策人：王若豪；关联REQ-211、REQ-212及既有REQ-209

用户要求开始到可玩期间提示放平，失败可重新加载，产品英文改中文。比较A同页遮罩（复用绑定、动作和清理，较小改动）与B独立准备页（页面独立，但增加导航与跨页引用/销毁测试）。用户明确回复“确认方案A（推荐）：游戏页上显示准备遮罩，完成后进入可玩状态”。

采用预建同页遮罩，仅由真实CALIBRATING/ERROR状态驱动；RUNNING才自动结束准备。重新加载提交原RESTART并读回快照，返回提交BACK；不新增业务状态、线程或游戏时钟。中文字体以SDK完整字体源静态子集方式集成，保留生成工具和许可依据；不得降低32稳定样本/5秒期限及100ms时序判据。全中文排版、glyph覆盖、局部刷新与生命周期须主机测试并在编译后实测。
