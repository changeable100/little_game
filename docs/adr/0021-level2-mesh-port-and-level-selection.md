# ADR-0021：同源第二关网格移植与PLAY选关

2026-11-13，负责人明确先移植第二关再验证，PLAY之后可以选关。此指令授权推进已完成电脑模型r4，取代ADR-0019此前仅电脑建模的阶段边界；旧M4拼盒图不冒充当前模型。

第二关采用同一建模源的静态索引网格，与显示共用顶点。相比旧32个盒和解析曲面拼接（不能准确表达当前尖脊/短坡外带/紧弯），使用只读网格及BVH连续球碰撞。水平面保留原轮廓，曲面仅降低采样密度；1308顶点/2397面，其中1603碰撞面，511个无递归BVH节点，最大顶面误差0.009883m。棋盘共面细分渲染与简化碰撞面精确共面。第一关保持原OBB/解析曲面和相机，第二关用映射到既有屏幕操控基底的坐标与0.8rad斜俯角/6m距离，复用原色/深度缓冲与5ms/8次碰撞预算。

两存档沿用第一关原始圆盘面数据及±0.42m触发范围，碰到圆盘区域承载面才激活，对应索引决定复活位置；绿色顶面真实接触触发，不以空间包围盒代替踩绿。

PLAY打开LEVEL 1/LEVEL 2选择。UI发布不可变关卡指针，物理工作线程建立对应会话，page以同一world显示。等待原IMU所有权释放后才能切换；全局run保持单调，包括尚未START便关闭READY页面的情况。旧动作不能因跨关复用run而被误收。重开/回点不换world。结算页不再显示“更多关卡即将推出”的旧占位，提示从PLAY选关。

排行榜按关卡独立RAM表、状态与存储键，第一关R3_TOP10_A/B保留原格式，第二关另用R3_L2_TOP10_A/B，后台写入逻辑沿用ADR-0020。两关均直接可选，不增加解锁门槛。

软件验证包含仅输入4.9m/s²上限通关、两个实际到达存档的分支跌落/复活、20次READY切换及旧run拒绝、真实LVGL选关/分榜/原生游戏页面与实际物理回放画面、100/50行一致与哨兵。真实设备帧时、触摸、输入手感和断电保存仍待硬件证据；不得把主机回放耗时当成人工成绩或真机性能。
