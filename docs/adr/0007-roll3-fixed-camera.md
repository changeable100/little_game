# ADR-0007：B三维视图固定相机与地面方向

- 日期：2026-11-08
- 状态：负责人已确认
- 关联：REQ-501、TC-501、ADR-0006

首批比较正对赛道与斜角透视，完整参数/权衡见 `docs/roll3-b-view-plan.md`。负责人明确回复“确认推荐相机，按此完成首批开发”，采用 camera=(3,-8,6)m，target=(3,0,0.2)m，world-up=(0,0,1)，垂直FOV=55°，near=0.15m、far=30m。

该方案屏幕右为世界+x，地面屏幕上为世界+y，便于A将已验证的IMU屏幕轴映射到相机水平基；斜角方案两侧面更明显，但需要混合世界x/y映射。接受正对方案侧面表现较弱的取舍，使用共享OBB及面明暗呈现坡道厚度和侧面，不额外修改碰撞几何。

相机实际up包含z分量，地面方向只表示水平投影。B不读取、交换或反向IMU输入；后续相机改变须先与A同步映射。本批接口仍为独立create/render/destroy和合成快照，三维独立任务/生产动作适配后续整合，二维入口保留。
