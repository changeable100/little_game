# ADR-0006：产品方向改为低多边形真3D、物理手感优先

- 日期：2026-11-08
- 状态：产品方向与独立物理任务方案A、分阶段迟帧策略已由负责人确认
- 决策人：王若豪

此前比较了丰富现有2D、固定视角2.5D、低多边形真3D三档。负责人明确要求“放宽延迟，我还是希望可以做3d的，可以不用太精细，主要是物理碰撞感要真实”。因此选择真实三维世界/碰撞与低精度三维画面，优先惯性、摩擦、碰撞响应、坡道及掉落体验。

备选2.5D较易复用图形加速与平面碰撞，但没有满足负责人此次继续选择真3D的方向。真3D接受更多渲染/碰撞/测试与性能风险，首版范围控制为一颗球与静态平台/坡道/墙，固定透视相机；世界与接触使用真实XYZ，固定相机不等于把二维图直接旋转。

允许重新设计此前100ms一律TIMING ERROR的要求；采用固定小步物理积分、有界迟帧处理与可恢复暂停。负责人已确认5ms/250ms分阶段计划及独立物理任务方案A，异常计时与接口在REQ-503/REQ-404修订、TC-503中明确。P0仅更新现有二维控制器，500ms显示心跳与独立任务在P1/P2实现；不能把本批固件说成已具备独立物理线程。

现有中文菜单、IMU/校准和已验证2D基线可以复用/保留；3D原型与当前2D实物结论分开。不得预先承诺帧率、碰撞精度或真实手感已经达标。新状态机/纯物理逻辑需有板上自检及主机验证，显示、响应和手感仍须学生上板取证。

确认记录：王若豪明确选择“独立物理任务，显示降帧时保持物理推进”的方案A，并确认按计划先P0迟帧容错再最小真3D原型。独立任务增加队列/快照、竞态和清理复杂度，相比沿用UI所有者补算方案，更符合显示降帧时保持物理连续的目标；接受此成本，分阶段验证。
