## 范围

本文件只定义成员 B 负责的 LVGL 界面与固定关卡数据，不替代整机 PRD。玩法、调度和首版范围已由成员 B 选择，仍需成员 A 评审共同接口与关卡碰撞尺寸后才能冻结。目标板型为 `sf32lb52-lchspi-ulp`，SiFli SDK v2.5.1，LVGL v9。

## 功能需求

| 需求 ID | 描述 | 优先级 | 验收标准 | 负责人 | 状态 |
|---|---|---|---|---|---|
| REQ-201 | 提供一张由界面和游戏逻辑共同读取的固定、只读迷宫关卡 | P0 | 同一地图数据包含尺寸、长度、起点、终点及格子；尺寸与数据长度相符；起终点不同且可通行；从起点可到达终点；地图结构非法时明确失败 | B | 评审草案 |
| REQ-202 | 在 LVGL 游戏区域绘制墙、通路、起点、终点和小球 | P0 | 五类元素可区分，完整地图位于屏幕可用区域内；绘制坐标与关卡行列一致；墙体及通路宽度通过成员 A 的小球半径/碰撞范围核对 | B | 评审草案 |
| REQ-203 | 提供开始、暂停、继续、重开和返回操作，并向集成层发送操作意图 | P0 | 每次操作只提交对应意图；投递失败显示未提交/可重试反馈；未收到模型快照确认前不得显示操作成功 | B | 评审草案 |
| REQ-204 | 按游戏状态快照显示阶段、小球位置和有效用时 | P0 | UI 不自建游戏位置、胜负或用时；显示用时直接取快照字段；重复快照不重复创建对象或累计时间 | B | 评审草案 |
| REQ-205 | 安全处理无效关卡、未知状态、过期快照和旧局操作 | P0 | 不越界访问、不把未知状态当作运行、不显示过期局数据；错误有可见反馈；旧局操作由共同契约定义并交由 A 侧拒绝 | B/A | 待契约评审 |
| REQ-206 | 支持游戏界面销毁后重新打开 | P1 | 重复进入/退出不会累积 LVGL 对象、事件回调或定时器；销毁后不再访问旧快照或上下文 | B | 评审草案 |
| REQ-207 | 游戏界面更新不阻塞 UI 线程且仅在 UI 线程操作 LVGL | P0 | UI 回调不执行传感器 I/O 或等待；绘制/刷新不重建整棵对象树；刷新来源唯一，不另建游戏推进任务 | B/A | 评审草案 |

## 已选择方向与待确认项

- 成员 B 选择：倾斜控制连续滚动小球。
- 成员 B 选择：游戏按有界步长在 UI 线程周期推进，IMU 提供受保护快照。
- 成员 B 选择：首版一张固定地图，不含选关。
- 待成员 A 共同评审：公共状态/快照/操作契约、刷新周期、地图编码、屏幕布局、球半径与通道净宽、计时和暂停语义。
- 不属于本期：随机地图、多关卡/选关、陷阱与生命值、联网排名、持久化成绩、界面侧碰撞/胜负判断。
