## 内部画面与中文

从160×180内部视口开始：RGB565色彩57600字节、16bit深度57600字节，共115200字节，另明确记录网格/临时数组等开销。通过一个LVGL图像/视口显示，不为每个三角形建对象；呈现放大需检查LVGL额外缓冲，不能把115200字节预写成整个程序的总内存。缓冲不按帧申请；分配失败、重复进入和释放均测试。

OBB顶点按center + 三个axis乘有符号half生成，使用同一world几何及RGB888材质色；球用少量三角形，法线/双色面随快照四元数(w,x,y,z)旋转。采用深度测试、近裁剪和视口裁剪/包围盒限制，投影半径随深度变化；近处球/墙遮挡和桥边落空按实际几何呈现，不加隐形栏杆或复制二维地图。

中文覆盖准备、放平校准、游玩、暂停/继续、掉落/回检查点、通关/重开/返回、输入错误、主机预览与内存不足。复用基线maze_font资源及既有许可/生成流程；若缺字，记录新增字体来源、许可和大小，不改SDK字体配置。状态只取r3_snapshot，不伪造CALIBRATING→RUNNING；本批没有生产动作接收者，游戏按钮禁用。预览的本地返回仅销毁视图，不发送旧二维动作。
