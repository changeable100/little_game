# 第二关电脑模型 r4

本轮下层中继宽度从2.8m扩大到3.8m，深度2.0m，柱体同步加宽；向绿色终点的陡降槽及终点向侧方挪0.8m，避免扩大平台侵入槽面。整关仍10.97×10.22m。

第二处保留两短坡与半圆中央承载带，按负责人确认将外半宽圆滑向上翘起0.22m；短坡外带在各自坡段平滑过渡到半圆，两接缝严格贴合。实际导出：20承载面平面面积无交叠、386位置地面连续、1544条默认视角球体射线无阻、47对象/9618非退化三角形、GLB2通过。任意角度及全体可玩偏移位置未穷举，不是物理通关。

打开index.html可离线旋转；“加宽平台”和“短坡半圆”查看本次修改；页面上方“游戏菜单预览”查看真实SDK LVGL渲染的启动菜单/选关/排行榜，满榜是合成测试数据。

按负责人后续指示，当前r4已同源移植到板端生产固件，PLAY可选两关；board/index.html为真实游戏C代码与SDK LVGL在主机生成的18个物理回放画面。板端曲面LOD相对本电脑模型顶面误差小于1厘米，显示与碰撞共用网格。完整仅输入回放42.705秒通过两个存档和两次陡降，零掉落；尚无本版本真机显示或性能结论。烧录与物理验证见docs/guides/第二关移植与选关-验证-2026-11-13.md。

生成：python tools/build_m4_desktop_model.py；校验：python tools/check_m4_desktop_model.py（NumPy）。生成源tools/m4_desktop_layout.py，查看器模板tools/m4_desktop_viewer.html，GLB为Y-up米制、OBJ为Z-up米制。source-seed.json是旧板端历史参考，当前布局不再读取它。
