# TC-510 三维入口低内存修复
上一版实物入口报-103。照片、原始指纹和判读见[旧版失败证据](../local-aa-2026-11-10/board-run01/analysis.md)。旧码可能由画面缓冲或刷新定时器返回，未收到旧串口，实际分配失败点未知。

新版颜色96000字节，工作区57600字节，两块独立。若100行工作区不足则重试50行，合计129600字节。两种模式都执行局部四点。主机故障注入验证两档申请、失败清理及独立定时器错误；36帧和密集边缘验证画面一致、无越界。主机单帧平均100行为1.466ms、50行为1.628ms。实机帧耗时和内存状态仍待验证。

## 一次复测
1. 按[COM与SDK准备](../p3-tuning-2026-11-09/README.md)操作，核验文件使用本目录 **firmware.json**。烧录脚本为 project/build_sf32lb52-lchspi-ulp_hcpu/uart_download.bat。
2. 用1000000 baud、8N1开始录串口，再复位。点“3D挑战”，记录 `[roll3:open]`。成功是 `result=0 depth_rows=100` 或 `result=0 depth_rows=50`；`-103` 表示画面分配失败，`-105` 表示刷新定时器创建失败。
3. 能进后，平放校准、慢移过绿坡与远处格纹、返回并再进一次。回传一张三维画面或短视频、包含 `[roll3:open]` 和几行 `[roll3:frame]` 的日志。若仍进不去，只需先发 `[roll3:open]` 附近和失败画面。新材料另放本目录board-run01。
