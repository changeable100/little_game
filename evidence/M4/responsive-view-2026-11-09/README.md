# 跟手、接缝与更细的渲染
REQ-508 / TC-508 / ADR-0010。A为240×200渲染与1.5倍LVGL抗锯齿缩放，显示区360×300，192000字节。绿坡和蓝色路面共边，输入对明显变化快速跟随，回平死区及时清零。刷新请求周期50ms，实际帧间隔待板测。

## 烧录和一次复测
沿用上一轮 [COM与SDK准备](../p3-tuning-2026-11-09/README.md)，镜像核验文件改为 **evidence/M4/responsive-view-2026-11-09/firmware.json**。运行 project/build_sf32lb52-lchspi-ulp_hcpu/uart_download.bat 后输入COM数字，1000000 baud、8N1记录串口并复位。
在3D挑战里平放校准。拍一段：轻倾开始移动 → 快速反倾 → 回平观察还滑多久 → 慢滚过绿坡与蓝平台连接处。尽量固定手机位置，拍清格纹和外轮廓。附上含启动自检和连续几行 `[roll3:frame]` 的串口日志。

`sample_age_max_ms` 是读取快照时最新已采用样本的最大年龄，`draw_max_ms` 是软件更新视图最大耗时，`gap_max_ms` 是两次画面更新起始之间的最大间隔。后两项包含不同阶段，不能相加当作端到端延迟；没有直接测量液晶出光。数据用于区分采样陈旧、绘制拖慢和已回平后的物理滑行。

## 软件证据
core-first保留反向首样本落入死区的失败，修正后core-retest全通过。view-first为真实SDK LVGL的七态、尺寸、缩放抗锯齿、20轮生命周期结果。sdk-first和sdk-final保留前后构建。主机图片为合成预览。
