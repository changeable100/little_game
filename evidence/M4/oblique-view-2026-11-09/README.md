# 斜俯视与边缘抗锯齿
REQ-507 / TC-507，基于02fa813。固定斜俯视，右和上以屏幕为基准。双采样分别处理遮挡并混合，画面区360×300。主机预览为host-*.png。117项核心和真实SDK LVGL回归及SDK编译均通过，完整输出在本目录。板端实际帧时、分配和锯齿改善程度待确认。
原P3视频支持可游玩、掉落与复活，用户报告像素跳动仍在。见../p3-tuning-2026-11-09/board-run01/analysis.md。旧固件与新版分别登记。

## 烧录
沿用上一轮 [COM和SDK准备](../p3-tuning-2026-11-09/README.md)，将核验路径换成 **evidence/M4/oblique-view-2026-11-09/firmware.json**。核验后运行 project/build_sf32lb52-lchspi-ulp_hcpu/uart_download.bat，输入COM端口数字。记录1000000 baud、8N1串口后复位，检查roll3自检summary PASS和ready=1。

## 一次复测
进三维挑战、平放校准。在起点分别轻压右沿和上沿，确认球向屏幕对应方向开始移动。对准坡道和转角慢移，观察外边缘、格纹和立体物块，拍同一段画面。如果仍跳动，尽量固定拍摄位置，记录是单格闪烁还是整帧跳动。保留串口日志及原始视频，在本目录board-run01登记。
