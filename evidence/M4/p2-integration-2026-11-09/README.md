## 一次板测

使用此工作副本生成的 `project/build_sf32lb52-lchspi-ulp_hcpu/uart_download.bat`，选择板卡的实际 COM 号。按已用过的 1000000 baud 打开串口，录下启动及一局操作。

1. 看到 `[roll3:selftest] summary PASS failures=0` 和 `[roll3:boot] ready=1` 后，在首页点击 **3D挑战**。
2. 平放按 **开始**，等 **游玩中** 后向右、向屏幕上方各轻倾一次。观察球是否同向移动。暂停几秒后继续，观察球和计时。
3. 让球从平台边缘掉落，点 **回检查点**，再点 **返回**。保存串口日志和一段视频或照片，放入本轮目录下的 `board-run01/`。启动、自检和状态变化使用同一份日志即可。

板上帧时、手感和真实三维输入方向等待此轮证据。
