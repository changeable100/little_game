# 第二关电脑模型审阅版 r1

本轮按负责人要求只完成电脑模型及检查，不移植、不构建或烧录新固件。

双击 `index.html` 可离线打开；拖动旋转，右键平移，滚轮缩放。顶部提供全貌、俯视、存档交接、柱体净空和双陡降视角。右侧可分层、拆层、隐藏柱体/护墙、选部件及查看沿线示意。沿线巡看是路径示意，没有物理解算，不代表可玩验收。

`level2-desktop.glb` 是Y-up、米制的标准glTF 2.0模型，可导入Blender等工具；`level2-desktop.obj` 是Z-up、带RGB顶点的模型。没有外部纹理或网络依赖。

## 这次实际修正

- 旧斜桥与存档台的平面交叠约0.112m²。新桥采用绕柱折返轮廓，在u=3处与存档台切齐，在u=-1处与西侧平台切齐；读取实际导出三角形再测，三个连接对象的共面交叠均为0。
- 原斜桥边缘侵入起点柱体，新桥靠柱边界v=-1.0，柱边v=-0.6，间距0.4m。
- 两个弯道支柱的柱顶直接使用弯道底面的同一组顶点，避免原方柱顶穿入弯道。存档台偏置支柱顶与台面底准确接合。
- 五条绿色终点承载带合并为连续阶梯圆盘模型，删除分带内部墙面。平台面与实体柱身可独立隐藏，默认一起显示。
- 保留约10.6×10.8m的紧凑分层布局、金色SAVE、两种不同方向/尺度的弯道、横向后纵向的两次陡降及绿色终点。

当前共有39个结构部件，加62个标记共101个对象；3515个导出三角形。没有宣称整个模型已经完成通用实体布尔/全路径碰撞验证。

## 验证与范围

`validation.txt`记录有限数值、法线、无退化三角形、GLB缓冲/节点范围、三处交接的共面重叠及起点柱体净空。`geometry-checks.json`记录建模判据。已实际打开并查看整关、俯视、交接与柱体图，操作分层、柱体开关、部件选择、沿线巡看和复位，控制台无错误。

新模型不同于当前C关卡表示，尤其折返连接、拟合柱顶和合并终点。尚未针对新模型进行物理通关，不能引用旧37.15秒/169项结果作为本模型物理验收。后续先审阅完整模型，再评估移植和性能。

## 可复现生成

```powershell
cd D:\peripheral_lab
python tools/build_m4_desktop_model.py
python tools/check_m4_desktop_model.py
```

`source-seed.json`是归档参考输入，生成工具在其基础上明确修正连接和柱顶，不自动读取新固件替换它。修改模型应修改生成工具/归档输入再重建，避免直接改导出文件失去可复现性。`tools/m4_desktop_viewer.html`是查看器模板。
